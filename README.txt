KresaManagement MVP - Prototype 0.1

ISI
- index.html: aplikasi web satu file berdasarkan struktur KresaFlow.

CARA MENCOBA
1. Ekstrak folder/ZIP.
2. Buka index.html dengan browser modern (Chrome/Edge).
3. Masuk ke Edit Profil untuk memasukkan nama usaha, logo, WhatsApp, Instagram, dan rekening.
4. Klik Booking Baru untuk mencoba formulir rental.
5. Gunakan Backup Data secara berkala. Restore digunakan untuk memulihkan file backup JSON.

FITUR PROTOTIPE
- Dashboard, kalender, cek ketersediaan, ringkasan keuangan, pengingat pembayaran, invoice JPG, WhatsApp, pencarian, bahasa, tema, profil usaha.
- Booking rental dengan lokasi CPW dan CPP, foto referensi baju akad dan resepsi, catatan, MUA, permintaan pengantin, total harga dan pembayaran.
- Layar aktivasi lisensi online; setelah aktivasi tersimpan, aplikasi dapat dibuka offline pada browser/perangkat yang sama (perlindungan dasar).
- Penyimpanan lokal di browser/perangkat. Foto diperkecil dan disimpan sebagai data lokal bersama booking.

PENTING
- Ini prototipe awal untuk pengujian, belum versi produksi.
- Data lokal tidak otomatis sinkron antara laptop dan HP. Gunakan Backup/Restore untuk memindahkan data.
- Karena foto disimpan pada storage browser, kapasitas browser terbatas. Jika banyak booking/foto, penyimpanan perlu ditingkatkan ke IndexedDB atau mekanisme file lokal yang lebih tepat sebelum rilis komersial.
- Hindari menghapus data browser sebelum membuat backup.
